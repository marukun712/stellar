stellar-reaction-display

ATProtocol 上の投稿に付けられた絵文字リアクションを表示する Web Component です。

Example

下のリアクションは実際のデータを取得して表示しています。

Usage

1. スクリプトを読み込む

<script src="https://marukun712.github.io/stellar/reaction-display.iife.js"></script>

2. タグを配置する

<reaction-display post-uri="at://did:plc:xxx/app.bsky.feed.post/yyy" ></reaction-display>

Attributes

属性 説明
post-uri リアクションを取得する投稿の AT URI
